Comparación de lentesCaptura la misma escena con cada cámara trasera para confirmar que las 3 encuadran distinto.

Apunta a una escena con profundidad (no una pared lisa) y pulsa «Capturar». Verás cómo cada lente recorta más de cerca: ultra gran angular → gran angular → teleobjetivo. Si dos salen idénticas, un lente podría no estar cambiando.
